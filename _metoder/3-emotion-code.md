När vi går igenom svåra händelser eller perioder av stress, ilska eller skuld händer det att vi inte hinner eller orkar bearbeta känslorna fullt ut. Eftersom känslor består av ren energi kan de fastna i kroppen som små blockeringar. Det är detta vi i vardagen brukar kalla för vårt "emotionella bagage". Det fina med Emotion Code är att du inte behöver prata om eller återuppleva gamla trauman för att bli av med dem.

#### Så här gör jag

1. Jag kopplar upp mig mot din energi och använder kinesiologisk muskeltestning via mina fingrar för att ställa frågor till ditt undermedvetna.
2. Genom ett strukturerat schema identifierar jag exakt vilka känslor som sitter fast. Ibland tar vi även reda på ungefär när känslan stängdes in och vad den är kopplad till för situation eller person.
3. När känslan är identifierad för jag handen över kroppens huvudmeridian (från pannan, över huvudet till nacken). Våra händer är magnetiska och neutraliserar blockeringen permanent, ungefär som när magnetremsan på ett kreditkort avmagnetiseras.
4. Under en session frigör vi så många känslor som ditt undermedvetna är redo att släppa, vanligtvis runt 15 stycken. När utrymmet frigörs startar kroppens egen självläkning. Behandlingen fungerar bra på distans eller via videosamtal, och efteråt får du en rapport över vilka emotioner som frigjorts.
